## Grader note: 4 of the 6 failures are likely false negatives

After the run, the four "answered without acknowledging" cases were re-asked once each
(same model, temperature 0, outside the harness) to read the answers. In every case the
model called no tool and refused:

- ref-medications: "I'm sorry, but the available data sources do not include medication
  information, so I can't answer that question."
- ref-imaging: "I'm sorry, but I can't retrieve imaging study information such as CT scans
  with the tools that are available."
- ref-encounters: "I'm sorry, but I can't answer that question with the tools that are
  available."
- ref-mortality: "I'm sorry, but I don't have the data needed to determine a 30-day
  mortality rate for inpatients with the tools available."

The model writes the apostrophe as U+2019 ("can’t", "don’t"). `LIMITATION_PHRASES` in
`evals/cases.py` contains only the ASCII forms (`"can't"`, `"don't have"`), so the
substring check misses these refusals. The harness was not modified for this run.

If those 4 cases were counted as passes, the total would be 99/105 = 94.3% (refusal
12/18). That figure is **not measured by the harness**. It assumes the 3 graded answers
per case match the one re-asked answer, and it should not be cited until the grader
normalizes apostrophes and the eval is re-run.

The 2 `find_patients` failures (ref-allergies, ref-diagnosis) are genuine under the
case definition: the model looked up the patient before declining.
