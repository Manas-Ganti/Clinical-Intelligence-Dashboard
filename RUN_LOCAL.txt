CLINICAL INTELLIGENCE DASHBOARD — LOCAL STARTUP
================================================

Two processes: the backend API (FastAPI/uvicorn on :8000) and the frontend
(Vite dev server on :5173). Repo root:
/Users/manasganti/portfolio-projects/clinical_dashboard


-------------------------------------------------
FASTEST — ONE COMMAND
-------------------------------------------------

./run.sh

  Installs anything missing, starts both servers, waits for the API to finish
  seeding, reports which model the Ask bar is wired to, and opens the browser.
  Ctrl+C stops both. Logs from both stream here, prefixed [api] / [web].

  ./run.sh --fresh       delete clinical.db first, so seeding re-runs
  ./run.sh --no-open     don't open a browser
  ./run.sh --no-install  skip the dependency check

The two-terminal version below is the same thing by hand — useful when you want
to restart one side without the other.


-------------------------------------------------
ONE-TIME SETUP
-------------------------------------------------

# 1. Python dependencies (backend)
python3 -m pip install -r requirements.txt

# 2. Frontend dependencies (Node 18+ required)
cd frontend && npm install && cd ..


-------------------------------------------------
TERMINAL 1 — BACKEND  (http://localhost:8000)
-------------------------------------------------

cd /Users/manasganti/portfolio-projects/clinical_dashboard

# Optional: start from a clean DB so sample data re-seeds on boot
rm -f clinical.db

# Start the API (seeds the sample data on first run)
python3 -m uvicorn backend.main:app --reload --port 8000

# Quick check (in another shell):
#   curl http://localhost:8000/health
#   curl http://localhost:8000/patients


-------------------------------------------------
TERMINAL 2 — FRONTEND  (http://localhost:5173)
-------------------------------------------------

cd /Users/manasganti/portfolio-projects/clinical_dashboard/frontend
npm run dev

# Then open http://localhost:5173 in a browser.
# The Vite dev server proxies /patients, /health, etc. to the backend on :8000.


-------------------------------------------------
OPTIONAL — NATURAL-LANGUAGE QUERY (the Ask bar)
-------------------------------------------------

# /query runs on Claude or on a VT ARC-hosted open model. Without the key its
# provider needs it returns 503 and the rest of the app still works. Put the
# settings in .env (loaded at import, so restart the backend after editing):

#   LLM_MODEL=gpt-oss-120b     # omit for Claude
#   VTARC_API_KEY=...          # llm.arc.vt.edu -> Settings -> Account -> API keys
#   ANTHROPIC_API_KEY=sk-ant-...

# Which one is live right now, and whether its key is present:
curl http://localhost:8000/query/model

# Every model the query layer knows about:
python3 evals/run_eval.py --list-models


-------------------------------------------------
NOTES
-------------------------------------------------

- Default database is SQLite (./clinical.db) — no setup needed.
  To use PostgreSQL instead:
    export DATABASE_URL="postgresql+psycopg2://user:pass@localhost:5432/clinical"

- Run the test suite:        python3 -m pytest -q
- Production frontend build:  cd frontend && npm run build
- Stop a server:             Ctrl+C in its terminal
